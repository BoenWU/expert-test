# 403 静态网页 需求

## 目标

提供一个静态的 403 页面，用于向访问者说明「没有访问权限」，并且不依赖服务端即可直接打开查看。

## 明确要求（用户明确提出）

- 交付物是一个 403 静态网页。
- 不需要服务端：页面不依赖后端服务即可完整呈现与使用。

## 核心行为与规则

1. **状态语义**：页面呈现 403 语义，直接告知访问者当前没有访问该内容的权限（用户明确提出，来自需求标题「403 静态网页」）。
2. **静态呈现**：页面以静态资源形式随交付内容提供，直接打开即可看到完整页面；不需要运行服务端进程、不需要接口数据即可显示内容（用户明确提出）。
3. **页面构成**：至少包含状态提示（403 或等价的「禁止访问」表达）和一句面向访问者的说明，使看不懂状态码的人也能理解发生了什么（推荐基线：仅用于让 403 语义对普通访问者可读，不扩大功能范围）。
4. **资源自包含**：页面所需的样式与资源随交付内容一并提供，页面打开时不因缺少外部资源而显示异常或空白（推荐基线：这是「直接打开即可完整呈现」的可观察条件，不指定具体技术或文件组织方式）。
5. **无额外能力**：页面不包含表单提交、身份校验、访问日志、服务端跳转等需要服务端参与的行为（用户明确要求「不需要服务端」的直接推论）。
