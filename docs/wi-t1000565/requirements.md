# 需求文档：爱心静态网页

## 目标

实现一个展示爱心图形的静态网页，用户通过浏览器打开即可查看，不需要服务端。

## 核心行为

- 页面在浏览器中打开后展示一个爱心形状。
- 页面为纯前端静态文件（HTML/CSS），不依赖任何服务端运行环境。
- 用户可直接在本地通过浏览器打开 HTML 文件查看爱心图形。

## 约束

- **用户明确提出**：不需要服务端。
- **未规定**：页面配色、动画效果、响应式适配、具体技术实现方式（如 CSS 绘制或 SVG）均未由用户指定，实现阶段可自行选择。

## 验收场景

### AC-01：浏览器打开页面展示爱心图形
- 验收条件：用户在浏览器中打开网页文件后，页面呈现一个可见的爱心形状。
- 入口类型：用户界面
- 验证动作：在浏览器中直接打开页面 HTML 文件。
- 预期结果：页面中心区域展示一个爱心图形，图形在页面加载后立即可见。
- 证据类型：runtime-render, visual-style
