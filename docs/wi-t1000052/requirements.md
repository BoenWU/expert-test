# 爱心主题静态网页 · 需求基线

## 目标

交付一个爱心主题的静态单页，供访客在浏览器中直接打开或经静态服务器托管访问时，看到完整的视觉呈现：居中的爱心主体图形、柔和的渐变背景、心跳与漂浮光点动效，以及简洁的标题与祝福文案。页面为纯前端实现，不依赖任何服务端接口与构建服务。

来源标注：除个别标注为"推荐"的收口项外，以下内容均为用户明确提出。

## 范围与排除

范围内：

- 一个爱心主题的静态单页，含爱心主体图形、柔和渐变背景、心跳与漂浮光点动效、简洁标题与祝福文案、居中排版。
- 桌面端与移动端两个指定视口下的响应式呈现。
- 纯前端实现，交付可直接打开或经静态服务器托管的页面文件。

范围外（用户明确提出）：

- 后端服务、数据库、用户账号与登录。
- 构建工具链与包管理依赖。
- 外部 CDN 或第三方在线资源。

范围外（用户未提出，不在本次范围）：

- 多页面导航、内容管理、数据持久化。

## 用户目标到验收

| 用户目标 | 对应 AC |
| --- | --- |
| 打开页面即可看到爱心图形、标题、祝福文案与动效，且无报错 | AC-01 |

## 核心行为与规则

### 页面内容（用户明确提出）

- 页面展示一个爱心主体图形，可用 CSS 绘制或 SVG 绘制，二者择一即可。
- 页面展示一个简洁的标题和一段祝福文案。
- 祝福文案的具体文字用户未规定，由实现选定，只需满足"简洁"并贴合爱心与祝福主题，不承载额外业务含义。
- 页面的主要内容区域采用居中排版。

### 视觉与动效（用户明确提出）

- 背景为柔和渐变，不使用生硬的高饱和撞色大色块。
- 动效包含爱心心跳节奏，以及漂浮光点效果；两者均需在页面上可见。
- 动效为常驻播放的装饰性动画，不需要用户操作触发。
- 动效不作为信息承载手段：装饰动画未播放时，页面内容（标题、文案、爱心图形）仍完整可读。

### 技术约束（用户明确提出）

- 使用 HTML + CSS 实现，可选少量 JavaScript；不引入框架、包管理器和构建步骤。
- 不发起任何后端接口请求，页面全部资源为本地静态文件（含样式、脚本、字体、图形）。
- 不引入后端、数据库与外部登录依赖。
- 不引用外部 CDN 或第三方在线资源。
- 交付物为可直接用浏览器打开、或经静态服务器托管的页面文件。

### 响应式适配（用户明确提出）

- 页面需在桌面与移动视口下均可正常使用，主体内容居中且不溢出容器。
- 用户明确要求覆盖的两个视口：桌面端 1440×900，移动端 390×844。
- 其他视口宽度用户未规定；实现不应在窄屏上出现横向滚动（推荐：以这两个视口作为必须满足的下限，并向中间宽度自然过渡）。

### 交互范围（用户明确提出）

- 页面只要求视觉呈现与基础动效，不要求表单、导航、路由、数据读写等业务交互。
- 少量 JavaScript 为可选项；若使用，仅用于装饰性动效，不影响内容可读性。

## 验收标准

| AC | 验收条件摘要 | 入口类型 | 证据类型 |
| --- | --- | --- | --- |
| AC-01 | 打开页面后爱心图形、标题、祝福文案与心跳、漂浮光点动效完整呈现，控制台无报错 | 用户界面 | runtime-render, visual-style |
| AC-02 | 1440×900 与 390×844 视口下无横向滚动，内容居中且不溢出 | 用户界面 | runtime-render, visual-style |
| AC-03 | 页面不发起后端接口请求，全部资源为本地静态文件，可离线打开 | 用户界面 | other |

### AC-01：页面打开即完整呈现爱心图形、标题、祝福文案与动效，控制台无报错
- 验收条件：用浏览器打开交付的页面文件后，爱心主体图形、标题、祝福文案均在首屏可见；心跳与漂浮光点动效可见地运行；浏览器控制台无报错，页面无资源加载失败。
- 入口类型：用户界面
- 验证动作：在浏览器中直接打开交付的页面文件（不经构建，不经后端服务）。
- 预期结果：爱心图形、标题与祝福文案完整渲染且居中排版；背景为柔和渐变；可观察到心跳节奏与漂浮光点动效；控制台无报错信息。
- 证据类型：runtime-render, visual-style, other

### AC-02：桌面与移动视口下无横向滚动且布局不溢出
- 验收条件：页面在 1440×900 与 390×844 两个视口下，均无横向滚动条，内容不超出视口边界，标题与祝福文案不发生截断或相互重叠。
- 入口类型：用户界面
- 验证动作：在浏览器中将视口分别调整为 1440×900 与 390×844，观察页面渲染结果。
- 预期结果：两个视口下页面均无横向滚动；爱心图形、标题、祝福文案完整位于可视区域内且保持居中；切换视口过程中无元素溢出。
- 证据类型：runtime-render, visual-style

### AC-03：不发起后端接口请求，全部资源为本地静态文件
- 验收条件：页面运行时除加载自身本地静态资源外，不发起任何后端接口请求（XHR / fetch / WebSocket）；样式、脚本、图形、字体等资源均来自交付目录内的本地文件。
- 入口类型：用户界面
- 验证动作：审查交付的页面文件与资源引用，并在浏览器中打开页面观察网络请求记录。
- 预期结果：网络记录中不存在指向后端接口或第三方域名的请求；全部资源引用为本地相对路径；页面可离线直接打开并完整渲染。
- 证据类型：other
