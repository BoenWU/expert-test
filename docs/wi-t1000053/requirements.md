# 需求：502 Bad Gateway 静态错误页

需求决策：**ready**。用户目标、交付形态与验收关注点已足够明确，可直接进入实现；以下区分用户明确提出、推荐基线与未规定事项。

## 目标

交付一个纯静态的 502 Bad Gateway 错误页，作为站点在网关异常时的对外提示页面。使用者打开页面即可知道「服务暂时不可用」，并可通过页面上的入口返回或重试。

## 范围

用户明确提出：

- 交付形态为纯静态资源（HTML/CSS，必要时少量原生 JS），不含任何服务端代码、后端接口、数据库或运行时服务。
- 页面可通过直接打开 `index.html` 渲染，也可部署到任意静态托管。
- 页面需呈现：清晰的 502 错误语义（502 / Bad Gateway 标题与错误说明文案）、品牌/标题区、返回入口。
- 需适配桌面与移动端视口。
- 资源引用使用相对路径或内联方式，离线环境下页面仍完整展示。

已排除（用户明确提出不包含）：后端接口、数据库、运行时服务。

未规定（本次不代为决定）：具体品牌名称与视觉素材、站点首页真实地址、需要支持的最低浏览器版本、多语言与主题切换、错误详情追踪编号。

## 核心行为与规则

1. **错误语义（用户明确提出）**：页面首屏范围内出现状态码 `502` 与 `Bad Gateway` 字样，并配有一段说明「服务暂时不可用 / 请稍后再试」性质的中文文案，使不熟悉技术术语的使用者也能理解当前状况。
2. **品牌/标题区（用户明确提出）**：页面上部有独立的品牌或标题区域，包含站点标识（文字或图形标识均可）与页面标题，与错误主体在视觉层级上可区分。
3. **返回与重试入口（用户明确提出，行为细节为推荐基线）**：页面提供至少一个可点击的返回或重试入口。推荐基线：提供「重新加载」入口用于重试当前页，并提供「返回上一页」入口；当浏览器无可用历史记录时，该入口不产生报错，页面保持可用。此细节保守、可逆，用户可调整。
4. **自包含资源（用户明确提出）**：样式等资源以相对路径引用或内联；不引用外部 CDN、远程字体或第三方脚本，断网或离线打开时页面外观与文案完整。
5. **无后端依赖（用户明确提出）**：页面不发起任何业务接口请求，也不依赖服务器端模板渲染；静态文件即可完整呈现。
6. **响应式布局（用户明确提出）**：桌面与移动视口下内容完整可读，无横向滚动条、文字截断或元素重叠。
7. **品牌文案占位（推荐基线）**：用户未提供品牌名称，本次采用可替换的占位品牌文字，集中在页面顶部一处便于后续替换；不引入外部图片资源。此选择保守、可逆。

## 验收场景

### AC-01：直接打开静态页面即可完整渲染
- 验收条件：以文件方式直接打开 `index.html` 时，页面在规定视口内完成渲染，错课文案与入口均可见，且控制台无因缺少服务端接口而产生的资源失败或报错。
- 入口类型：用户界面
- 验证动作：在浏览器中直接打开 `index.html`（不经任何后端服务）。
- 预期结果：页面完整呈现 502 错误内容，无空白区域、无加载失败占位，无指向后端接口的请求。
- 证据类型：runtime-render

### AC-02：502 错误语义与返回/重试入口可见可用
- 验收条件：页面上同时可见 `502`、`Bad Gateway` 标识与中文错误说明文案，并提供至少一个可点击的返回或重试入口；点击重试入口后当前页面重新加载。
- 入口类型：用户界面
- 验证动作：打开页面查看首屏文案，并点击重试入口。
- 预期结果：错误语义与说明文案清晰可读；点击重试后页面重新加载并仍显示同一错误页；返回入口点击不产生脚本错误。
- 证据类型：runtime-render, interaction

### AC-03：桌面与移动视口下布局完整可读
- 验收条件：在桌面视口（约 1440×900）与移动视口（约 390×844）下，标题区、错误说明与入口按钮均完整显示，无横向溢出、文字截断或元素重叠。
- 入口类型：用户界面
- 验证动作：分别在桌面与移动视口宽度下查看页面并滚动至页面底部。
- 预期结果：两种视口下内容均完整可读，页面不出现横向滚动，元素间距与按钮触达区域合理。
- 证据类型：visual-style, runtime-render

### AC-04：资源自包含，离线可完整展示
- 验收条件：页面引用的样式与脚本均为内联或同目录相对路径，不依赖远程字体、CDN 或第三方资源；断开网络后打开页面，视觉与文案保持完整。
- 入口类型：用户界面
- 验证动作：检查页面资源引用，并在无网络条件下刷新或重新打开页面。
- 预期结果：页面外观与联网时一致，无字体回退造成的排版错乱，无外部资源加载失败提示。
- 证据类型：runtime-render
