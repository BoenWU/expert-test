# 架构基线：404 静态网页

## 1. 依据与范围

本设计以已批准的 `docs/wi-t1000070/requirements.md` 为唯一产品基线（快照哈希 `sha256:6c3473b1ec96b87d5ff43189dc996f0c37a7fe1045a867c0f7da90cb0375d8e5`），内部以 `AC-01`、`AC-02` 作为覆盖清单，不在本文重复业务规则与验收场景。

交付范围是一个地址未命中提示页面。设计只给出必要的技术承载方式，产品语义、文案含义与验收要求均沿用需求基线。

## 2. 技术路线

- 采用 `simple-frontend` 精简路线：`npm` + React + Vite 单页应用，构建产物为纯静态资源（HTML/CSS/JS/图片），无运行时服务端。
- 页面数据全部内置在静态资源中，渲染过程不发起任何接口请求，满足「无服务端环境同样完整呈现」的约束。
- 构建配置使用相对资源路径（`base: './'`），使 `dist/index.html` 既能由任意静态文件托管服务提供，也能在浏览器中直接以文件方式打开，对应需求中「可直接静态方式打开」的交付方式。

## 3. 页面与交互范围

- 单一视图：404 未找到页面，一屏内呈现 404 状态标识与「页面不存在／未找到」的说明文字，辅以简短引导说明用户可尝试的操作方向。
- 不引入多页面或前端路由，页面不依赖当前访问地址、查询参数或任何服务端返回信息。
- 交互为可选增强，不作为交付前提：需求未规定返回首页或站内导航入口，本设计不提供指向站内其他页面的链接（当前无既有站点结构，避免产生失效链接），仅保留文案引导；若实现阶段加入「返回上一页」，只允许使用浏览器历史能力，不得引入站外链接或外部跳转。
- 视觉与文案语言由实现阶段在需求允许范围内决定，不改变页面传达「404 / 页面未找到」的核心含义。

## 4. 数据与状态归属

- 无持久化数据、无浏览器存储写入（不需要 `localStorage`）、无会话状态、无跨页面共享状态。
- 页面不读取、不缓存业务数据；所有展示内容为构建时写入静态资源的常量。
- 无跨设备、跨浏览器或跨用户的数据共享，也不存在需要同步的权威数据源。

## 5. UI 选型与视觉方向

- 不引入组件库（Ant Design 等默认方案面向管理工作台，此单页无表格、表单或组织筛选等需求，引入会显著增大静态体积且无收益），使用原生语义化 HTML 加少量手写 CSS。
- 视觉方向：单屏居中布局，突出大号 404 数字标识，其下为标题「页面未找到／不存在」与一段说明文字；保持留白充足、层级清晰、在移动端窄屏可自适应。
- 资源约束：仅使用系统字体栈与本地打包的图标/装饰，不引用外部 CDN、外部字体或第三方统计脚本，保证离线与无网络条件下外观一致。
- 可访问性：使用语义化标题结构（页面主标题唯一）、正文与背景保持足够对比度、装饰元素标记为对辅助技术隐藏。

## 6. 实现入口与运行方式

- 应用入口：Vite 入口 `index.html` 加载 `src/main.jsx`，挂载根组件 `App`，`App` 渲染单一 `NotFoundPage` 视图；样式集中在 `src/` 下的样式文件中。
- 开发预览：`npm install` 后执行 `npm run dev`，通过 Vite 开发服务器本地查看，仅用于开发调试。
- 静态交付：`npm run build` 生成 `dist/` 目录，目录内文件即最终交付物，可直接复制到任意静态托管位置或本地打开。
- 部署基线文件 `deploy/Dockerfile` 与 `.dockerignore` 由前端部署初始化器生成，属工作区基线，不属本设计产物；其中静态托管镜像仅承载构建产物，不引入应用服务端逻辑。

## 7. 边界与不实现项

- 不实现服务端错误处理与请求路由重写（需求已列为范围外）；真实 404 状态码由托管方配置，页面本身只负责未找到信息的呈现。
- 不虚构服务接口、数据库、认证授权、后台任务、外部集成或同步层。
- 不生成技术契约、工作区初始化描述或实现计划；实现阶段按本基线落地。

## 8. 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 技术栈 | React + Vite 单页静态构建 | 复用前端部署基线，产物为纯静态文件 |
| 资源路径 | 相对路径（`base: './'`） | 支持直接以文件方式打开与任意子路径托管 |
| 组件体系 | 无组件库，手写 CSS | 单页无复杂交互，减小体积、减少外部依赖 |
| 数据层 | 无 | 需求不涉及任何数据读写或持久化 |

## 9. 可重复验证方式

- `AC-01`：执行 `npm run build` 后在浏览器直接打开 `dist/index.html`，确认 404 状态标识与未找到说明文字可见、布局完整、控制台无脚本错误。
- `AC-02`：在未启动任何服务端进程、且禁用网络的条件下打开同一文件，确认页面内容完整、无资源加载失败提示、无空白区域；同时确认构建产物中不存在对外网络请求。
- 页面为确定性的静态渲染，无动画时序、随机结果、定时任务或异步外部事件，因此不设额外的测试控制入口，也不需要预置状态或固定结果机制。
