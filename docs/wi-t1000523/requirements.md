# 需求：爱心静态网页

## 目标

用户明确提出：实现一个展示爱心图形的静态网页，不需要服务端。

页面为纯前端静态资源（HTML/CSS），可直接通过浏览器打开运行，不依赖任何后端服务、接口或运行时环境。

## 核心行为

1. 页面在浏览器中打开后，渲染出一个爱心图形。
2. 页面为纯静态资源，仅包含 HTML 与 CSS（或内联样式），无 JavaScript 服务端调用、无接口请求、无构建依赖。
3. 用户可直接在浏览器中通过本地文件打开该页面查看效果。

## 技术约束

- 用户明确提出：不需要服务端。
- 页面应使用标准 Web 技术（HTML/CSS）实现，确保浏览器原生支持、无需额外插件或运行时。

### AC-01：浏览器打开页面可见爱心图形

- 验收条件：用户在浏览器中打开静态网页文件后，页面渲染出一个可辨识的爱心图形。
- 入口类型：用户界面
- 验证动作：在浏览器中直接打开页面文件（本地文件协议或静态服务均可）。
- 预期结果：页面正常加载并显示一个爱心图形，图形清晰可辨识。
- 证据类型：runtime-render, visual-style
