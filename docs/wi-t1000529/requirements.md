# 需求文档：502 静态网页

## 目标

实现一个 502 Bad Gateway 错误页面，作为纯静态 HTML 文件，不依赖任何服务端逻辑。

## 核心行为与规则

- 页面为自包含的静态 HTML 文件，可直接在浏览器中打开，无需服务端运行环境。
- 页面内容展示 502 错误状态，包含错误码和简要说明文本（如"Bad Gateway"或"网关错误"）。
- 页面样式内联于 HTML 文件中，不依赖外部 CSS/JS 资源。
- **用户明确提出**：不需要服务端。
- **未规定**：页面具体视觉风格（配色、布局）、是否包含重试按钮或返回链接、语言（中/英文）等细节，由实现阶段在合理范围内决定。

## 验收场景

### AC-01：浏览器可正常展示 502 错误页面

- 验收条件：静态 HTML 文件直接在浏览器中打开后，页面正常渲染并显示 502 错误信息。
- 入口类型：用户界面
- 验证动作：将静态 HTML 文件在浏览器中直接打开（file 协议）。
- 预期结果：页面正常加载并渲染，可见"502"错误码及对应的错误描述文本，不出现资源加载失败或空白页面。
- 证据类型：runtime-render
