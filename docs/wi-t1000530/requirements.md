# 需求：爱心静态网页

## 目标

在浏览器中展示一个静态爱心页面，页面不依赖任何服务端，用户打开后可直接看到爱心呈现。

## 用户明确提出

- 页面主体为爱心图案。
- 页面为静态网页，不需要服务端。

## 推荐基线

- 页面以单文件 HTML 形式交付，双击或通过浏览器直接打开即可查看，不依赖外部网络资源与服务端。
- 爱心图案使用 CSS 或 HTML 画布渲染，保证零后端、零运行时依赖。

## 未规定

- 爱心具体颜色、尺寸、动画效果、字体、背景风格等视觉细节未由用户指定，实现时可在保守、可逆的前提下选择常规风格，保留后续调整空间。
- 是否需要部署、部署目标平台未规定，不在当前基线中指定。

## 核心行为与规则

1. 页面在浏览器中打开后即可看到完整的爱心图案，无需登录、提交或任何服务端交互。
2. 页面自包含：所需样式与结构内联在 HTML 文件中，不依赖外部服务端接口或动态加载远程资源。
3. 页面以静态 HTML 文件形式交付，可直接被浏览器解析展示。

## 验收场景

### AC-01：打开页面可见爱心图案
- 验收条件：在浏览器中打开交付的静态页面后，能看到完整的爱心图案。
- 入口类型：用户界面
- 验证动作：在浏览器中打开交付的 HTML 文件。
- 预期结果：页面渲染出一个可识别的爱心图案，不依赖服务端或后端请求。
- 证据类型：runtime-render, visual-style
