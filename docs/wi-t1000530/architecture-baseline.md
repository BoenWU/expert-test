# 架构基线：爱心静态网页

- Work Item: wi-t1000530
- 应用类型: simple-frontend（compact 路由）
- 批准需求: docs/wi-t1000530/requirements.md（sha256:7e5f3288201d7fc400a147e5cb117ba54621da9d91cd1e864ee63cb81357a153）

## 技术选型

- 交付形态：单个自包含的静态 HTML 文件（`index.html`）。
- 渲染方式：使用内联 CSS 在 HTML 画布中渲染爱心图案，不引入外部框架、构建工具或运行时库。
- 运行方式：用户在浏览器中通过文件路径（`file://`）双击打开 `index.html` 即可查看；无需启动开发服务器或任何后端服务。
- 文件位置：`index.html` 位于仓库根目录。

## 页面与交互范围

- 页面主体为一个可识别的爱心图案，居中显示。
- 视觉细节（颜色、尺寸、背景风格）在保守、可逆的前提下选择常规风格，保留后续调整空间。
- 页面无登录、无表单提交、无用户交互请求、无路由跳转。
- 不存在应用状态、表单数据、用户输入或任何需要持久化的记录，因此不使用 `localStorage` 或其他存储。

## 浏览器状态与数据归属

- 本页面无任何应用数据。不涉及服务端权威数据、数据库、认证/权限、后台任务、外部服务集成或跨用户/设备共享。
- 页面完全自包含：所需 HTML 结构与 CSS 样式均内联在 `index.html` 中，不依赖外部网络资源或动态加载远程资源。

## 实现入口与运行方式

- 入口文件：`index.html`（浏览器直接解析）。
- 运行命令：无。直接在浏览器中打开该文件即可。
- 构建/打包：无。不使用构建工具或包管理器。

## AC 覆盖

- AC-01（打开页面可见爱心图案）：通过在浏览器中打开 `index.html` 验证页面渲染出一个可识别的爱心图案，不依赖服务端或后端请求。该 AC 为确定性视觉渲染，无需预置状态、固定结果或手动推进事件；刷新页面即可恢复初态。

## 边界

- 不虚构服务/API、数据库、认证、后台任务、外部集成或同步层。
- 不生成 `technical-contract.md`、`workspace-bootstrap.json`、ADR 或实现计划。
- 部署目标平台未由用户指定，不在当前架构基线中约束。
