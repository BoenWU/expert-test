## 2. 实现说明（对照已批准基线的可观察行为）

按设计基线交付单文件 `404.html`，全部内容随文件一同呈现：

- **F-01（404 标识）**：首屏以 `<h1 class="error-code">404</h1>` 展示 108px 醒目错误标识，页面加载即可见，无需滚动。
- **F-02（提示文案）**：简体中文友好文案“抱歉，您访问的页面不存在”，辅以一行地址失效说明；`<html lang="zh-CN">` + `<meta charset="utf-8">`，无乱码风险。
- **F-03（单一静态页面）**：全部内容内联于同一文件，无任何需服务端处理才能显示的内容。
- **F-04/F-05（返回首页入口）**：按钮形态入口 `<a class="back-home" href="/">返回首页</a>`，文字清晰表明作用，点击后浏览器跳转到站点根路径 `/`（按推荐基线 R-01）。
- **F-06（样式随静态资源交付）**：CSS 全部内联于 `<style>`，无外部样式表、无构建步骤，打开即完整呈现。
- **F-07（桌面默认窗口完整可见）**：`body` 使用 flex 单屏居中布局，内容卡片 `max-width: 520px` + 响应式 padding，桌面默认窗口下一屏完整呈现，不产生横向滚动；入口为 144px 最小点击区域按钮，边界清晰。
- **R-02（视觉风格）**：克制的错误页风格——浅灰底、白色卡片、深色文字、单一蓝色强调色用于分隔线与入口按钮；字体使用系统字体栈，不引入外部视觉资源。

无状态、无本地存储、无网络请求（`noindex` 元信息按错误页常规约定设置，不产生行为依赖）。
